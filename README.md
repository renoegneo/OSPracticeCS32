# OSProjectsCS32: практические по проектированию операционных систем


**Выполнил:** Курбатов Максим CS32

Практические работы по дисциплине «Проектирование операционных систем». Во всех работах выполнен **вариант B** (средний уровень сложности). Среда: Ubuntu (WSL2) на Windows 11, Python 3.12, Bash.

Каждая работа лежит в своей папке `prNN/`. В ней есть `README.md` с реальными выводами команд, таблицами и объяснениями, а также исходники (в `pr01` только README, там нет программ).

## Содержание

| Папка | Тема | Что сделано |
|---|---|---|
| `pr01` | Установка Linux и терминал | второй пользователь и группа, общий каталог `/srv/shared` с правами по группе, разница `su` и `sudo`, настройка `~/.bashrc` (алиасы, переменная окружения) |
| `pr02` | Bash и системные вызовы | скрипты на Bash, наблюдение за системными вызовами |
| `pr03` | Процессы в Linux | дерево процессов из `/proc`, `fork` + `exec`, зомби и сирота, копирование памяти при записи (COW) |
| `pr04` | Потоки | сравнение 1 потока, потоков и процессов на счёте и вводе-выводе, роль GIL, общая память |
| `pr05` | Планирование CPU | симулятор FCFS, SJF, SRTF, Priority (со старением), RR; метрики и график |
| `pr06` | Синхронизация | «производитель–потребитель» на кольцевом буфере (семафоры и условные переменные), барьер, потерянное пробуждение |
| `pr07` | Межпроцессное взаимодействие | клиент–сервер на FIFO и на Unix-сокетах, `shared_memory` против `Pipe`, сравнительная таблица механизмов IPC |
| `pr08` | Взаимоблокировки | алгоритм банкира, детектор по графу ожидания, `TrackedLock`, обедающие философы |

## Как запускать

Команды и ожидаемые результаты описаны в `README.md` внутри каждой папки. Например:

```bash
cd pr05
python3 sched.py --algo rr --quantum 3 set1.txt
```

Скрипты, которым нужны входные данные, генерируют их сами (например, `pr04/gen_numbers.py`, `pr05/gen_sets.py`). Большой `pr04/numbers.txt` (около 39 МБ) в репозиторий не входит, он в `.gitignore`.
